# 💄 Cosmetics Sales Analytics Project

**A Data Analytics Project using Excel, SQL, Python, and Power BI**

## 📌 Project Overview

The Cosmetics Sales Analytics Project focuses on analyzing cosmetics sales, customer behavior, product performance, and business trends using data analytics tools.

The main objective is to transform raw sales data into meaningful insights that help businesses understand sales performance, identify popular products, analyze customer purchasing patterns, and support better business decisions.

This project was developed as part of my Data Analytics learning journey and practical project work.

## 🎯 Project Objectives

- Analyze overall cosmetics sales and revenue.
- Identify top-performing products and categories.
- Understand monthly sales trends.
- Compare sales performance across different states.
- Analyze customer and order data.
- Explore the relationship between discounts and sales.
- Create visualizations and dashboards for easy interpretation.
- Explore sales trends to support future planning.

## 🚀 How to Run the Project

### Step 1: Clone the repository

```bash
git clone https://github.com/fathimahiba88917/Main_Project.git
```

### Step 2: Open the project folder

```bash
cd Main_Project
```

### Step 3: Install the required Python libraries

```bash
pip install pandas matplotlib numpy
```

Install any additional libraries required by the Python scripts if they are not already available.

### Step 4: Run the analysis script

```bash
python cosmetics_analysis.py
```

### Step 5: Run the dashboard

```bash
python tk_dash.py
```

Make sure Python is installed and the required CSV files are available in the expected project locations before running the scripts.
